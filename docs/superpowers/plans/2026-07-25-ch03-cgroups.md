**The cgroup v1 vs v2 difference:** In v1, each controller had its own hierarchy mount. In v2 (unified), all controllers share one hierarchy. **Lifecycle:**
```
mkdir /sys/fs/cgroup/mygroup     # creates a new struct cgroup
  └─ kernfs_create_dir()         # creates the kernfs directory
       └─ cgroup_mkdir()         # kernel/cgroup/cgroup.c
            └─ cgroup_create()   # allocates struct cgroup, initialises subsys states

echo $PID > /sys/fs/cgroup/mygroup/cgroup.procs  # attach process
  └─ cgroup_migrate()            # kernel/cgroup/cgroup.c
       └─ cgroup_migrate_finish() # updates task->cgroups (the css_set pointer)

rmdir /sys/fs/cgroup/mygroup     # destroy (only when cgroup.procs is empty)
  └─ cgroup_rmdir()
       └─ cgroup_destroy_locked()
            └─ css_kill_scheduling()
```

**Locking discipline:**
- `cgroup_mutex` — global mutex for hierarchy modifications (mkdir, rmdir, controller enable/disable)

- `kernfs_mutex` — protects the kernfs node (the directory)
- Per-cgroup RCU: `subsys[]` array entries are RCU-protected

**Object graph:**

task_struct

                                                                         └─ subsys[] (same CSS)

**Section 1 — Controller architecture overview**

`struct cgroup_subsys` — the vtable for each controller:
```c
// include/linux/cgroup-defs.h
struct cgroup_subsys {
    struct cgroup_subsys_state *(*css_alloc)(struct cgroup_subsys_state *parent_css);
    int (*css_online)(struct cgroup_subsys_state *css);
    void (*css_offline)(struct cgroup_subsys_state *css);
    void (*css_free)(struct cgroup_subsys_state *css);
    int (*can_attach)(struct cgroup_taskset *tset);
    void (*attach)(struct cgroup_taskset *tset);
    int (*fork)(struct task_struct *task);
    void (*exit)(struct task_struct *task);
    void (*release)(struct task_struct *task);
    /* ... */
    int id;           /* controller ID (memory_cgrp_id, cpu_cgrp_id, ...) */
    const char *name; /* "memory", "cpu", "io", "pids" */
    bool threaded;    /* threaded mode support */
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/include/linux/cgroup-defs.h

`struct cgroup_subsys_state` — base type embedded in every per-controller state struct:
```c
struct cgroup_subsys_state {
    struct cgroup        *cgroup;   // which cgroup owns this state
    struct cgroup_subsys *ss;       // which subsystem
    refcount_t            refcnt;
    unsigned long         flags;
    struct cgroup_subsys_state *parent;
    struct rcu_head       rcu_head;
    struct work_struct    destroy_work;
    struct rcu_work       destroy_rwork;
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/include/linux/cgroup-defs.h

**Section 2 — memory controller**

Key files (cgroup v2):
- `memory.current` — current memory usage in bytes (read-only)
- `memory.max` — hard limit; OOM kill if exceeded
- `memory.high` — soft limit; processes get throttled above this
- `memory.min` — memory protection; kernel won't reclaim below this
- `memory.low` — soft memory protection
- `memory.swap.max` — swap limit
- `memory.stat` — detailed breakdown (anon, file, kernel, slab, etc.)
- `memory.events` — oom, oom_kill, max events counter

Key struct: `struct mem_cgroup` in `mm/memcontrol.c`:
```c
// mm/memcontrol.h (partial, most important fields)
struct mem_cgroup {
    struct cgroup_subsys_state css;  // must be first — embedded CSS
    struct page_counter memory;      // tracks memory usage + limit
    struct page_counter swap;        // tracks swap usage + limit
    struct page_counter memsw;       // memory + swap combined
    /* ... */
    bool                oom_group;   // kill whole cgroup on OOM?
    struct mem_cgroup_per_node __percpu *nodeinfo; // per-NUMA-node stats
    struct list_head    event_list;  // memory events
    spinlock_t          event_list_lock;
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/mm/memcontrol.h

`struct page_counter` — the core accounting struct: `atomic_long_t usage`, `long max` (the limit). When `usage > max`, the OOM killer fires.

OOM kill path:
```
page fault → charge_memcg() → mem_cgroup_charge() → try_charge()
  └─ [usage > max] → mem_cgroup_oom() → out_of_memory()
       └─ oom_kill_process() → sends SIGKILL to the process
```

**Section 3 — cpu controller**

Key files (cgroup v2):
- `cpu.stat` — `usage_usec`, `user_usec`, `system_usec`, `nr_throttled`, `throttled_usec`
- `cpu.max` — `<quota> <period>` in microseconds; `100000 100000` = 100% of one CPU; `200000 100000` = 200% (2 CPUs)
- `cpu.weight` — CFS weight (1–10000, default 100); relative CPU share
- `cpu.weight.nice` — nice-value alias for cpu.weight

Key struct: `struct task_group` in `kernel/sched/sched.h`:
```c
struct task_group {
    struct cgroup_subsys_state css;
    /* CFS bandwidth control */
    struct cfs_bandwidth    cfs_bandwidth;  // quota/period/runtime accounting
    /* per-CPU runqueues */
    struct sched_entity   **se;    // one per CPU
    struct cfs_rq         **cfs_rq; // one per CPU
    unsigned long           shares; // cpu.weight
    /* ... */
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/kernel/sched/sched.h

CFS bandwidth throttling path:
```
scheduler tick → scheduler_tick() → task_tick_fair()
  └─ entity_tick() → update_curr() → account_cfs_rq_runtime()
       └─ [runtime exhausted] → throttle_cfs_rq()
            └─ rq→curr != tg's task → dequeue_entity() → process must wait
```
Unthrottled when the period timer fires: `sched_cfs_period_timer()` → `do_sched_cfs_period_timer()` → `unthrottle_cfs_rq()`

Live observation:
```bash
# See CPU quota for a pod (kubernetes sets this from resources.limits.cpu):
cat /sys/fs/cgroup/kubepods/pod<uid>/cpu.max

# See throttling stats (nr_throttled > 0 means the pod hit its CPU limit):

# bpftrace: trace CFS throttling
bpftrace -e 'kprobe:throttle_cfs_rq {
    printf("throttled: pid=%d comm=%s\n", pid, comm);
}'
```

**Section 4 — io controller**

Key files (cgroup v2):
- `io.stat` — per-device: `rbytes`, `wbytes`, `rios`, `wios`, `dbytes`, `dios`
- `io.max` — hard limit: `<major:minor> rbps=<n> wbps=<n> riops=<n> wiops=<n>`
- `io.weight` — relative I/O weight (1–10000)
- `io.latency` — target latency in milliseconds per device

Key struct: `struct blkcg` in `block/blk-cgroup.h`:
The block I/O cgroup controller intercepts block I/O at the `submit_bio()` level and applies throttling via the BFQ or mq-deadline scheduler.

Live observation:
```bash

cat /sys/fs/cgroup/kubepods/pod<uid>/io.stat

```

**Section 5 — pids controller**

Key files (cgroup v2):
- `pids.current` — current number of processes + threads
- `pids.max` — limit; `fork()` fails with EAGAIN if this would be exceeded
- `pids.events` — `max` counter (how many times the limit was hit)

Key struct: `struct pids_cgroup` in `kernel/cgroup/pids.c`:
```c
struct pids_cgroup {
    struct cgroup_subsys_state css;
    atomic64_t  counter;   // current count
    atomic64_t  limit;     // pids.max
    local_t     events_limit; // pids.events counter
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/kernel/cgroup/pids.c

Enforcement path: `pids_fork()` is called by `copy_process()` for every `clone()`. It increments the counter and checks against the limit — if over, returns `-EAGAIN`, causing `clone()` to fail.

Live observation:
```bash
cat /sys/fs/cgroup/kubepods/pod<uid>/pids.current
cat /sys/fs/cgroup/kubepods/pod<uid>/pids.max
```

**Section 6 — Enabling controllers**

In cgroup v2, controllers must be explicitly enabled at each level by writing to `cgroup.subtree_control`:
```bash
# Enable memory and cpu controllers for children:
echo "+memory +cpu" > /sys/fs/cgroup/mygroup/cgroup.subtree_control

# Verify:
cat /sys/fs/cgroup/mygroup/cgroup.controllers
```
The `cgroup.controllers` file shows which controllers are available at this level. The top-level `/sys/fs/cgroup/cgroup.controllers` shows all controllers compiled into the kernel.

## Task 3: `struct css_set` and task-to-cgroup membership

**Files:**
- Create: `03-cgroups/kernel/03-c-css-set.md`

- [ ] **Step 1: Write `03-cgroups/kernel/03-c-css-set.md`**

**Section 1 — The problem `css_set` solves**

A task belongs to exactly one cgroup per controller. With 12+ controllers in a typical system, storing one pointer per controller directly in `task_struct` would be wasteful when most tasks share the same cgroup membership. `css_set` is the solution: a hash-table-cached struct that holds all per-controller state pointers for one unique combination of cgroup memberships.

**Section 2 — struct css_set**
```c
// include/linux/cgroup-defs.h
struct css_set {
    struct cgroup_subsys_state *subsys[CGROUP_SUBSYS_COUNT]; // one per controller
    refcount_t   refcount;         // how many tasks use this set
    struct css_set *dom_cset;      // default hierarchy cgroup set
    struct cgroup  *dfl_cgrp;      // cgroup in the default (v2) hierarchy
    int             nr_tasks;      // number of tasks in this set
    struct list_head tasks;        // list of tasks (via task_struct.cg_list)
    struct list_head mg_tasks;     // tasks mid-migration
    struct list_head task_iters;   // ongoing task iterators
    struct list_head e_cset_node[CGROUP_SUBSYS_COUNT]; // per-subsystem list node
    struct list_head threaded_csets; // threaded css_sets
    struct hlist_node hlist;       // hash table node
    struct list_head cgrp_links;   // links to all member cgroups
};
```
Source: https://elixir.bootlin.com/linux/v6.9/source/include/linux/cgroup-defs.h

**Section 3 — How task_struct links to css_set**
```c
// include/linux/sched.h (relevant fields)
struct task_struct {
    /* ... */
    struct css_set __rcu *cgroups; // RCU-protected pointer to css_set
    struct list_head      cg_list; // list node in css_set.tasks
    /* ... */
};
```
The `cgroups` pointer is RCU-protected. Reads: `rcu_dereference(task->cgroups)`. Writes (during migration): protected by `css_set_lock` spinlock.

**Section 4 — css_set sharing**
When two tasks have identical cgroup memberships across ALL controllers, they share the same `css_set` instance. The kernel maintains a global hash table (`css_set_table`) keyed on the combination of `cgroup_subsys_state *` pointers. This is an important optimization: on a system with 1000 processes all in the same cgroups, there is only ONE `css_set` (refcount=1000) instead of 1000 separate structs.

**Section 5 — Task migration path**
When a PID is written to `cgroup.procs`:
```
write("cgroup.procs", pid)
  └─ cgroup_procs_write()              # kernel/cgroup/cgroup.c
       └─ __cgroup_procs_write()
            └─ cgroup_attach_task()
                 └─ cgroup_migrate()
                      ├─ cgroup_migrate_add_task()  # build migration set
                      ├─ cgroup_migrate_execute()   # call subsys->attach() for each
                      └─ cgroup_migrate_finish()    # swap task->cgroups pointer
```

**Section 1 — Kubernetes QoS classes and cgroup hierarchy**

Three QoS classes and how they map to cgroup paths:

| QoS Class | Condition | cgroup path |
|-----------|-----------|-------------|
| Guaranteed | All containers have requests == limits for CPU and memory | `/sys/fs/cgroup/kubepods/pod<uid>/` |
| Burstable | At least one container has a request or limit | `/sys/fs/cgroup/kubepods/burstable/pod<uid>/` |
| BestEffort | No requests or limits set | `/sys/fs/cgroup/kubepods/besteffort/pod<uid>/` |

**Section 2 — How kubelet translates resource requests/limits to cgroup parameters**

Table showing the mapping:

| Pod spec field | cgroup v2 file | Value written | Example |
|----------------|----------------|---------------|---------|
| `resources.limits.memory` | `memory.max` | bytes | `268435456` (256Mi) |
| `resources.requests.memory` | `memory.min` | bytes | `134217728` (128Mi) |
| `resources.limits.cpu` | `cpu.max` | `<quota> 100000` | `100000 100000` (1 CPU) |
| `resources.requests.cpu` | `cpu.weight` | weight formula | `cpu.weight = (1024 * milliCPU) / 1000` |

**Section 3 — Verifying cgroup setup for a running pod**

```bash

echo "Cgroup: $CGROUP_PATH"

# Check memory limit
cat "${CGROUP_PATH}/memory.max"

# Check CPU quota (quota period)

# Check current memory usage
cat "${CGROUP_PATH}/memory.current"

# Check OOM events

```

**Section 4 — The OOM kill cycle**

Explain what happens when a container exceeds `memory.max`:
1. Process tries to allocate memory
2. `mem_cgroup_charge()` finds `usage > max`
3. Kernel calls `mem_cgroup_out_of_memory()` → `out_of_memory()` → OOM killer
4. OOM killer selects the highest-scoring process in the cgroup (`oom_badness()`)
5. Sends SIGKILL
6. kubelet detects the pod's container has exited (watches CRI events)
7. kubelet records `OOMKilled` as the reason in `pod.status.containerStatuses[].lastState.terminated.reason`

Verify:
```bash
kubectl describe pod nginx | grep -A5 "Last State"
# OOMKilled appears here

# On the node:
dmesg | grep -i "oom\|killed process"
```

**Section 5 — CPU throttling detection**

CPU throttling is invisible from `kubectl` but visible at the cgroup level:
```bash
# Check if a pod's CPU is being throttled:
cat /sys/fs/cgroup/kubepods/pod${POD_UID}/cpu.stat
# Look for: nr_throttled > 0 and throttled_usec > 0

# The throttled_usec / (usage_usec + throttled_usec) ratio gives the throttle %
```
Explain: CPU throttling is a common source of latency spikes in Kubernetes — a container that sets `limits.cpu=100m` will be severely throttled if it bursts above that, even if the node has spare CPU capacity.

**Section 6 — Namespace vs cgroup: complementary isolation**

Brief comparison connecting ch02 and ch03:
- Namespaces control VISIBILITY (what a process can see)
- cgroups control RESOURCE USAGE (how much a process can consume)
- A container needs both: namespaces to isolate its view, cgroups to limit its resource footprint
- The cgroup namespace (CLONE_NEWCGROUP, covered in ch02) controls what the cgroup hierarchy LOOKS LIKE from inside the container

**Section 7 — kube-inspect integration preview**

After checkpoint 03, `kube-inspect --pod <uid> --cgroup` will show:
- Memory current / max / high
- CPU usage_usec / throttled_usec / nr_throttled
- pid count / max

#define CGROUP_ROOT   "/sys/fs/cgroup"
#define DEMO_CGROUP   CGROUP_ROOT "/cgroup-demo-test"
#define DEMO_MEM_MAX  (32 * 1024 * 1024)  /* 32 MiB */
#define DEMO_PID_MAX  10

static int write_file(const char *path, const char *value)
{
    int fd = open(path, O_WRONLY);
    if (fd < 0) {
        fprintf(stderr, "open %s: %s\n", path, strerror(errno));
        return -1;
    }
    ssize_t n = write(fd, value, strlen(value));
    close(fd);
    if (n < 0) {
        fprintf(stderr, "write %s: %s\n", path, strerror(errno));
        return -1;
    }
    return 0;
}

static int read_file(const char *path, char *buf, size_t len)
{
    int fd = open(path, O_RDONLY);
    if (fd < 0) return -1;
    ssize_t n = read(fd, buf, len - 1);
    close(fd);
    if (n < 0) return -1;
    buf[n] = '\0';
    /* strip trailing newline */
    if (n > 0 && buf[n-1] == '\n') buf[n-1] = '\0';
    return 0;
}

static void setup_cgroup(void)
{
    char path[256];
    char value[64];

    /* Create the cgroup directory */
    if (mkdir(DEMO_CGROUP, 0755) < 0 && errno != EEXIST) {
        perror("mkdir " DEMO_CGROUP);
        exit(1);
    }
    printf("[setup] Created cgroup: %s\n", DEMO_CGROUP);

    /* Enable memory and pids controllers in the parent (root) cgroup.
     * This is required before the child cgroup can use them. */
    snprintf(path, sizeof(path), "%s/cgroup.subtree_control", CGROUP_ROOT);
    if (write_file(path, "+memory +pids") < 0) {
        fprintf(stderr, "hint: may already be enabled, continuing\n");
    }

    /* Set memory limit: 32 MiB */
    snprintf(value, sizeof(value), "%d", DEMO_MEM_MAX);
    snprintf(path, sizeof(path), "%s/memory.max", DEMO_CGROUP);
    if (write_file(path, value) < 0) exit(1);
    printf("[setup] memory.max = %d bytes (%d MiB)\n",
           DEMO_MEM_MAX, DEMO_MEM_MAX / (1024 * 1024));

    /* Set pids limit */
    snprintf(value, sizeof(value), "%d", DEMO_PID_MAX);
    snprintf(path, sizeof(path), "%s/pids.max", DEMO_CGROUP);
    if (write_file(path, value) < 0) exit(1);
    printf("[setup] pids.max = %d\n", DEMO_PID_MAX);
}

static void show_stats(void)
{
    char buf[256];
    char path[256];

    snprintf(path, sizeof(path), "%s/memory.current", DEMO_CGROUP);
    if (read_file(path, buf, sizeof(buf)) == 0)
        printf("[stats] memory.current = %s bytes\n", buf);

    snprintf(path, sizeof(path), "%s/pids.current", DEMO_CGROUP);
    if (read_file(path, buf, sizeof(buf)) == 0)
        printf("[stats] pids.current   = %s\n", buf);

    snprintf(path, sizeof(path), "%s/memory.events", DEMO_CGROUP);
    if (read_file(path, buf, sizeof(buf)) == 0)
        printf("[stats] memory.events:\n%s\n", buf);
}

static void cleanup_cgroup(void)
{
    /* Remove all processes from the cgroup first */
    rmdir(DEMO_CGROUP);
    printf("[cleanup] Removed %s\n", DEMO_CGROUP);
}

static void child_work(void)
{
    char path[256];
    char pidstr[32];
    pid_t mypid = getpid();

    /* Move ourselves into the demo cgroup */
    snprintf(path, sizeof(path), "%s/cgroup.procs", DEMO_CGROUP);
    snprintf(pidstr, sizeof(pidstr), "%d", (int)mypid);
    if (write_file(path, pidstr) < 0) {
        fprintf(stderr, "[child] failed to join cgroup\n");
        exit(1);
    }
    printf("[child pid=%d] joined cgroup %s\n", (int)mypid, DEMO_CGROUP);

    /* Verify we're in the right cgroup */
    char cgroup_buf[256];
    if (read_file("/proc/self/cgroup", cgroup_buf, sizeof(cgroup_buf)) == 0)
        printf("[child pid=%d] /proc/self/cgroup: %s\n", (int)mypid, cgroup_buf);

    /* Allocate memory in steps, printing current usage */
    const int step = 4 * 1024 * 1024;  /* 4 MiB per step */
    const int steps = 10;
    printf("[child] allocating memory in %d MiB steps (limit: %d MiB)...\n",
           step / (1024 * 1024), DEMO_MEM_MAX / (1024 * 1024));

    for (int i = 0; i < steps; i++) {
        void *p = malloc(step);
        if (!p) {
            printf("[child] malloc failed at step %d (OOM or limit)\n", i + 1);
            break;
        }
        memset(p, 0xAB, step);  /* actually touch the pages */
        printf("[child] allocated %d MiB total\n", (i + 1) * step / (1024 * 1024));
    }

    printf("[child] done\n");
    exit(0);
}

int main(void)
{
    printf("=== cgroup v2 demo ===\n");
    printf("Requires root (needs to write to /sys/fs/cgroup)\n\n");

    setup_cgroup();

    printf("\n[parent] forking child into cgroup...\n");
    pid_t child = fork();
    if (child < 0) {
        perror("fork");
        return 1;
    }
    if (child == 0) {
        child_work();
        /* not reached */
    }

    /* parent: wait and show stats */
    printf("[parent] waiting for child pid=%d\n", (int)child);
    int status;
    waitpid(child, &status, 0);

    if (WIFEXITED(status))
        printf("[parent] child exited with status %d\n", WEXITSTATUS(status));
    else if (WIFSIGNALED(status))
        printf("[parent] child killed by signal %d (%s)\n",
               WTERMSIG(status),
               WTERMSIG(status) == 9 ? "SIGKILL — likely OOM killed by cgroup" : "");

    printf("\n");
    show_stats();
    cleanup_cgroup();
    return 0;
}

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
	"strconv"
	"strings"
)

// CgroupStats holds parsed stats from a cgroup v2 directory.
type CgroupStats struct {
	Path string

	// memory
	MemoryCurrent uint64 // memory.current — bytes in use
	MemoryMax     string // memory.max — "max" or bytes
	MemoryHigh    string // memory.high — "max" or bytes
	MemoryStat    map[string]uint64 // memory.stat key-value pairs
	MemoryEvents  map[string]uint64 // memory.events key-value pairs

	// cpu
	CPUStat    map[string]uint64 // cpu.stat key-value pairs
	CPUMax     string            // cpu.max — "<quota> <period>" or "max <period>"
	CPUWeight  uint64            // cpu.weight

	// pids
	PidsCurrent uint64 // pids.current
	PidsMax     string // pids.max — "max" or number
}

// readUint64File reads a file containing a single uint64 value.
func readUint64File(path string) (uint64, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return 0, err
	}
	return strconv.ParseUint(strings.TrimSpace(string(data)), 10, 64)
}

// readStringFile reads a file and returns its trimmed content.
func readStringFile(path string) string {
	data, err := os.ReadFile(path)
	if err != nil {
		return "(unavailable)"
	}
	return strings.TrimSpace(string(data))
}

// readKVFile parses a file with "key value" lines (like memory.stat, cpu.stat).
func readKVFile(path string) map[string]uint64 {
	f, err := os.Open(path)
	if err != nil {
		return nil
	}
	defer f.Close()

	result := make(map[string]uint64)
	scanner := bufio.NewScanner(f)
	for scanner.Scan() {
		fields := strings.Fields(scanner.Text())
		if len(fields) != 2 {
			continue
		}
		v, err := strconv.ParseUint(fields[1], 10, 64)
		if err == nil {
			result[fields[0]] = v
		}
	}
	return result
}

// cgroupPathForPID returns the cgroup v2 path for a given PID by reading
// /proc/<pid>/cgroup and extracting the "0::<path>" line.
func cgroupPathForPID(pid int) (string, error) {
	data, err := os.ReadFile(fmt.Sprintf("/proc/%d/cgroup", pid))
	if err != nil {
		return "", fmt.Errorf("reading /proc/%d/cgroup: %w", pid, err)
	}
	for _, line := range strings.Split(string(data), "\n") {
		if strings.HasPrefix(line, "0::") {
			relPath := strings.TrimPrefix(line, "0::")
			return filepath.Join("/sys/fs/cgroup", relPath), nil
		}
	}
	return "", fmt.Errorf("no cgroup v2 entry in /proc/%d/cgroup", pid)
}

// ReadCgroupStats reads all available stats from the given cgroup path.
func ReadCgroupStats(cgroupPath string) (*CgroupStats, error) {
	if _, err := os.Stat(cgroupPath); err != nil {
		return nil, fmt.Errorf("cgroup path %s: %w", cgroupPath, err)
	}

	s := &CgroupStats{Path: cgroupPath}

	// memory
	if v, err := readUint64File(filepath.Join(cgroupPath, "memory.current")); err == nil {
		s.MemoryCurrent = v
	}
	s.MemoryMax = readStringFile(filepath.Join(cgroupPath, "memory.max"))
	s.MemoryHigh = readStringFile(filepath.Join(cgroupPath, "memory.high"))
	s.MemoryStat = readKVFile(filepath.Join(cgroupPath, "memory.stat"))
	s.MemoryEvents = readKVFile(filepath.Join(cgroupPath, "memory.events"))

	// cpu
	s.CPUStat = readKVFile(filepath.Join(cgroupPath, "cpu.stat"))
	s.CPUMax = readStringFile(filepath.Join(cgroupPath, "cpu.max"))
	if v, err := readUint64File(filepath.Join(cgroupPath, "cpu.weight")); err == nil {
		s.CPUWeight = v
	}

	// pids
	if v, err := readUint64File(filepath.Join(cgroupPath, "pids.current")); err == nil {
		s.PidsCurrent = v
	}
	s.PidsMax = readStringFile(filepath.Join(cgroupPath, "pids.max"))

	return s, nil
}

func printStats(s *CgroupStats) {
	fmt.Printf("Cgroup: %s\n\n", s.Path)

	fmt.Printf("=== Memory ===\n")
	fmt.Printf("  current:     %s\n", formatBytes(s.MemoryCurrent))
	fmt.Printf("  max (limit): %s\n", formatMaxString(s.MemoryMax))
	fmt.Printf("  high:        %s\n", formatMaxString(s.MemoryHigh))
	if s.MemoryStat != nil {
		for _, key := range []string{"anon", "file", "kernel", "slab", "sock"} {
			if v, ok := s.MemoryStat[key]; ok {
				fmt.Printf("  stat.%-12s %s\n", key+":", formatBytes(v))
			}
		}
	}
	if s.MemoryEvents != nil {
		for _, key := range []string{"oom", "oom_kill", "max"} {
			if v, ok := s.MemoryEvents[key]; ok {
				fmt.Printf("  events.%-9s %d\n", key+":", v)
			}
		}
	}

	fmt.Printf("\n=== CPU ===\n")
	fmt.Printf("  max (quota/period): %s\n", s.CPUMax)
	fmt.Printf("  weight:             %d\n", s.CPUWeight)
	if s.CPUStat != nil {
		for _, key := range []string{"usage_usec", "user_usec", "system_usec", "nr_throttled", "throttled_usec"} {
			if v, ok := s.CPUStat[key]; ok {
				fmt.Printf("  stat.%-15s %d\n", key+":", v)
			}
		}
	}

	fmt.Printf("\n=== PIDs ===\n")
	fmt.Printf("  current: %d\n", s.PidsCurrent)
	fmt.Printf("  max:     %s\n", s.PidsMax)
}

func formatBytes(b uint64) string {
	switch {
	case b >= 1024*1024*1024:
		return fmt.Sprintf("%.2f GiB (%d bytes)", float64(b)/(1024*1024*1024), b)
	case b >= 1024*1024:
		return fmt.Sprintf("%.2f MiB (%d bytes)", float64(b)/(1024*1024), b)
	case b >= 1024:
		return fmt.Sprintf("%.2f KiB (%d bytes)", float64(b)/1024, b)
	default:
		return fmt.Sprintf("%d bytes", b)
	}
}

func formatMaxString(s string) string {
	if s == "max" || s == "(unavailable)" {
		return s
	}
	v, err := strconv.ParseUint(s, 10, 64)
	if err != nil {
		return s
	}
	return formatBytes(v)
}

func usage() {
	fmt.Fprintf(os.Stderr, "usage: cgroup-stats <cgroup-path>\n")
	fmt.Fprintf(os.Stderr, "       cgroup-stats --pid <pid>\n")
	fmt.Fprintf(os.Stderr, "\nExamples:\n")
	fmt.Fprintf(os.Stderr, "  cgroup-stats /sys/fs/cgroup/user.slice\n")
	fmt.Fprintf(os.Stderr, "  cgroup-stats --pid 1\n")
	fmt.Fprintf(os.Stderr, "  cgroup-stats --pid $$  # your current shell\n")
}

func main() {
	if len(os.Args) < 2 {
		usage()
		os.Exit(1)
	}

	var cgroupPath string

	if os.Args[1] == "--pid" {
		if len(os.Args) < 3 {
			usage()
			os.Exit(1)
		}
		pid, err := strconv.Atoi(os.Args[2])
		if err != nil {
			fmt.Fprintf(os.Stderr, "error: invalid PID %q\n", os.Args[2])
			os.Exit(1)
		}
		p, err := cgroupPathForPID(pid)
		if err != nil {
			fmt.Fprintf(os.Stderr, "error: %v\n", err)
			os.Exit(1)
		}
		fmt.Printf("PID %d cgroup path: %s\n\n", pid, p)
		cgroupPath = p
	} else {
		cgroupPath = os.Args[1]
	}

	stats, err := ReadCgroupStats(cgroupPath)
	if err != nil {
		fmt.Fprintf(os.Stderr, "error: %v\n", err)
		os.Exit(1)
	}

	printStats(stats)
}

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
	"strconv"
	"strings"

// PodStats holds cgroup v2 resource stats for a pod.
// Fields are read directly from /sys/fs/cgroup/kubepods/pod<uid>/
type PodStats struct {
	CgroupPath string

	// memory
	MemoryCurrent uint64            // memory.current bytes
	MemoryMax     string            // memory.max ("max" or bytes as string)
	MemoryHigh    string            // memory.high
	MemoryStat    map[string]uint64 // memory.stat
	MemoryEvents  map[string]uint64 // memory.events (oom, oom_kill, max)

	// cpu
	CPUStat   map[string]uint64 // cpu.stat (usage_usec, throttled_usec, nr_throttled)
	CPUMax    string            // cpu.max
	CPUWeight uint64            // cpu.weight

	// pids
	PidsCurrent uint64 // pids.current
	PidsMax     string // pids.max
}

func readUint64(path string) (uint64, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return 0, err
	}
	return strconv.ParseUint(strings.TrimSpace(string(data)), 10, 64)
}

func readString(path string) string {
	data, err := os.ReadFile(path)
	if err != nil {
		return ""
	}
	return strings.TrimSpace(string(data))
}

func readKV(path string) map[string]uint64 {
	f, err := os.Open(path)
	if err != nil {
		return nil
	}
	defer f.Close()
	result := make(map[string]uint64)
	scanner := bufio.NewScanner(f)
	for scanner.Scan() {
		fields := strings.Fields(scanner.Text())
		if len(fields) == 2 {
			if v, err := strconv.ParseUint(fields[1], 10, 64); err == nil {
				result[fields[0]] = v
			}
		}
	}
	return result
}

// podCgroupPath finds the cgroup v2 path for a pod UID by searching
// /sys/fs/cgroup/kubepods/ for a directory matching the pod UID.
func podCgroupPath(podUID string) (string, error) {
	root := "/sys/fs/cgroup/kubepods"
	var found string
	err := filepath.WalkDir(root, func(path string, d os.DirEntry, err error) error {
		if err != nil {
			return nil // skip unreadable dirs
		}
		if d.IsDir() && strings.Contains(d.Name(), podUID) {
			found = path
			return filepath.SkipAll
		}
		return nil
	})
	if err != nil {
		return "", fmt.Errorf("searching %s: %w", root, err)
	}
	if found == "" {
		return "", fmt.Errorf("pod %s not found under %s", podUID, root)
	}
	return found, nil
}

// ReadPodStats returns cgroup v2 stats for the given pod UID.
func ReadPodStats(podUID string) (*PodStats, error) {
	cgPath, err := podCgroupPath(podUID)
	if err != nil {
		return nil, err
	}

	s := &PodStats{CgroupPath: cgPath}

	s.MemoryCurrent, _ = readUint64(filepath.Join(cgPath, "memory.current"))
	s.MemoryMax = readString(filepath.Join(cgPath, "memory.max"))
	s.MemoryHigh = readString(filepath.Join(cgPath, "memory.high"))
	s.MemoryStat = readKV(filepath.Join(cgPath, "memory.stat"))
	s.MemoryEvents = readKV(filepath.Join(cgPath, "memory.events"))

	s.CPUStat = readKV(filepath.Join(cgPath, "cpu.stat"))
	s.CPUMax = readString(filepath.Join(cgPath, "cpu.max"))
